INSTALL & SETUP

Install AVENLOCK on your device

Installation guidance belongs on its own screen, separate from login and account creation.

▣

Windows / macOS

Open the secure website in Chrome or Edge. Use the browser’s Install app action, then open it from your applications.

◫

Android

Open the website in Chrome and choose Install app or Add to Home Screen. Open the installed app once while connected.

▯

iPhone / iPad

Open the website in Safari. Use Share → Add to Home Screen and launch from your Home Screen.

The first installation requires access to the website. Once the offline application shell is securely cached, previously stored device vaults can be opened without internet.
